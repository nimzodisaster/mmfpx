Package: mmfpx
Title: Fractional Polynomial Mixed-Effects Utilities
Version: 0.4.0
Author: Josh  Lee


Description: Tools for exploring fractional polynomial relationships in neuroimaging and related longitudinal data. Provides utilities for bagged fractional polynomial normalization of regional measures as well as mixed-effects model selection using multiple fractional polynomials with support for raw, ratio, or standard deviation-based age scaling.
